# Генератор чеков CSV → HTML → PDF

Интерактивный Python-скрипт для массовой генерации PDF-чеков из CSV-данных и HTML-шаблонов. Конвертация выполняется через [WeasyPrint](https://weasyprint.org/).

Поддерживаются **Windows** и **macOS**, корректное отображение **кириллицы**, перенос длинных строк в таблицах.

---

## Возможности

- Чтение CSV с полями, содержащими запятые в кавычках (`csv.DictReader`)
- Подстановка данных в HTML-шаблон по плейсхолдерам `{{ key }}`
- Сохранение промежуточного HTML и итогового PDF для каждой записи
- Интерактивный выбор CSV-файла, шаблона и диапазона записей
- Автоматическое открытие PDF после генерации
- Осмысленные имена файлов: `receipt_001.pdf`, `receipt_002.pdf` и т.д.

## Установка

### 1. Python

Требуется **Python 3.10+**.

### 2. Зависимости

```bash
pip install -r requirements.txt
```

Или напрямую:

```bash
pip install weasyprint
```

### 3. Системные библиотеки для WeasyPrint

WeasyPrint использует Pango, Cairo и GDK-PixBuf.

**Windows**

1. Скачайте и установите [GTK3 Runtime](https://github.com/nicklasb/gtk3-windows/releases).
2. Перезапустите терминал.
3. Подробнее: [документация WeasyPrint](https://doc.courtbouillon.org/weasyprint/stable/first_steps.html#windows).

**macOS**

```bash
brew install pango cairo gdk-pixbuf libffi
```

### 4. Шрифты (рекомендуется)

Для корректной кириллицы в PDF положите один из шрифтов в папку `fonts/`:

| Файл | Источник |
|------|----------|
| `Roboto-Regular.ttf` | [Google Fonts — Roboto](https://fonts.google.com/specimen/Roboto) |
| `LiberationSans-Regular.ttf` | [Liberation Fonts](https://github.com/liberationfonts/liberation-fonts) |

Если шрифт в `fonts/` не найден, скрипт попробует системный Arial (Windows / macOS).

## Запуск

```bash
python generate_receipts.py
```

### Пошаговый сценарий

1. **Выбор CSV** — скрипт показывает список файлов из `data/`, введите номер или имя.
2. **Выбор шаблона** — аналогично для файлов из `templates/`.
3. **Просмотр данных** — первые 5 строк и общее количество записей.
4. **Выбор записей** для обработки:

   | Ввод | Действие |
   |------|----------|
   | Enter (пусто) | Все записи |
   | `3` | Только запись № 3 |
   | `3-7` | Записи с 3 по 7 |
   | `1,5,9` | Записи 1, 5 и 9 |

5. **Генерация** — PDF сохраняются в `output/`, каждый файл автоматически открывается.

## Формат CSV

Первая строка — заголовки. Пример (`data/sample_receipts.csv`):

```csv
order_id,date,items,total
001,2026-08-28,"<table>...</table>",335.50
```

### Поддерживаемые имена колонок

Скрипт распознаёт как английские, так и русские заголовки:

| Плейсхолдер | Возможные имена колонок |
|-------------|-------------------------|
| `{{ order_id }}` | `order_id`, `номер`, `number`, `id`, `№`, `no` |
| `{{ date }}` | `date`, `дата` |
| `{{ items }}` | `items`, `товары`, `products`, `goods` |
| `{{ total }}` | `total`, `сумма`, `amount`, `итого` |

Любая другая колонка CSV также доступна как плейсхолдер с тем же именем, например `{{ customer_name }}`.

Колонка `items` может содержать готовую HTML-таблицу — она будет вставлена в шаблон как есть.

## HTML-шаблон

Пример (`templates/receipt_template.html`):

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Чек {{ order_id }}</title>
</head>
<body>
    <h1>Кассовый чек</h1>
    <p><strong>Номер:</strong> {{ order_id }}</p>
    <p><strong>Дата:</strong> {{ date }}</p>
    {{ items }}
    <p class="total">Итого: {{ total }} ₽</p>
</body>
</html>
```

Плейсхолдеры поддерживают оба формата: `{{ key }}` и `{{key}}`.

Стили таблиц (границы, центрирование, перенос длинных строк) добавляются автоматически при генерации PDF.

## Имена выходных файлов

PDF и HTML именуются на основе значения **первой колонки** CSV:

```
receipt_001.pdf
receipt_002.pdf
```

Если первая колонка пуста — используется номер строки: `receipt_003.pdf`.

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| `WeasyPrint не установлена` | `pip install weasyprint` |
| `cannot load library 'libgobject-2.0-0'` (Windows) | Установите GTK3 Runtime, перезапустите терминал |
| Квадраты вместо кириллицы в PDF | Положите `Roboto-Regular.ttf` в `fonts/` |
| `CSV-файл пуст` | Проверьте, что файл содержит заголовки и хотя бы одну строку данных |
| `Не удалось разобрать выбор записей` | Используйте формат: номер, `3-7` или `1,5,9` |

## Используемые технологии

- **Стандартная библиотека Python** — `csv`, `pathlib`, `glob`, `subprocess`, `re`, `os`, `sys`
- **WeasyPrint** — конвертация HTML → PDF
- Подстановка данных — `str.replace()` (без Jinja2 и других шаблонизаторов)

## Исходный промпт

Техническое задание, по которому был создан проект:

> Напиши Python-скрипт, который:
>
> Читает CSV-файл с колонками данных для чеков (например, номер, дата, товары, суммы).
>
> Загружает HTML-шаблон, содержащий плейсхолдеры (например, `{{ order_id }}`, `{{ date }}`, `{{ items }}`, `{{ total }}`).
>
> Для выбранных строк CSV подставляет данные в HTML-шаблон.
>
> Сохраняет итоговый HTML для каждой выбранной строки.
>
> Конвертирует каждый HTML в отдельный PDF с помощью библиотеки WeasyPrint.
>
> Сохраняет PDF-файлы в папку `/output` (создаёт её, если необходимо).
>
> После генерации автоматически открывает каждый PDF в браузере или системной программе просмотра.
>
> Работает на Windows и macOS.
>
> Обеспечивает корректное отображение кириллицы (подключает шрифт Roboto или Liberation Sans).
>
> Переносит длинные строки в таблицах (CSS: `word-wrap: break-word`, `overflow-wrap: break-word`).
>
> Отображает таблицы с аккуратными границами и выравниванием по центру (CSS: `border-collapse: collapse`, центрирование текста).
>
> ### Дополнительные требования по интерактивному выбору
>
> При запуске скрипт должен сканировать указанные директории:
>
> - папку `./data` (или другую, заданную переменной) на наличие CSV-файлов;
> - папку `./templates` (или другую) на наличие HTML-шаблонов.
>
> Если директорий не существует, скрипт должен создать их и вывести сообщение с просьбой поместить туда файлы.
>
> Скрипт выводит в консоль список найденных CSV-файлов (с номерами) и предлагает пользователю выбрать один, введя номер или имя файла.
>
> Затем скрипт выводит список найденных HTML-шаблонов и предлагает выбрать один аналогичным образом.
>
> После выбора CSV-файла скрипт должен показать первые несколько строк (например, первые 5) и общее количество записей.
>
> Пользователю предлагается выбрать, какие записи обрабатывать:
>
> - все записи;
> - конкретную запись по номеру строки (1-based);
> - диапазон записей (например, «3-7»);
> - несколько номеров через запятую (например, «1,5,9»).
>
> Если пользователь оставляет ввод пустым, по умолчанию обрабатываются все записи.
>
> Все подсказки и сообщения об ошибках должны быть понятными и на русском языке.
>
> ### Технические требования
>
> - Использовать только стандартные библиотеки для работы с CSV, файловой системой, subprocess для открытия PDF, os, sys, glob.
> - Для конвертации HTML в PDF использовать WeasyPrint (установка через `pip install weasyprint`).
> - Для подстановки данных в шаблон можно использовать `str.replace()` или регулярные выражения (без подключения шаблонизаторов).
> - Учесть, что в CSV могут быть поля с запятыми внутри кавычек — использовать стандартный `csv.DictReader`.
> - Имена выходных PDF-файлов должны быть осмысленными (например, на основе значения первой колонки или номера строки: `receipt_001.pdf`).
> - Скрипт должен корректно обрабатывать ошибки (отсутствие файлов, пустой CSV, неверный выбор пользователя) и не завершаться аварийно.
